Built in the open

Emerald Markets runs on open-source marketplace software from the ground up — the code behind listings, bidding, and payments is public and auditable, not a black box.

No proprietary lock-in

Your listings and account data aren't tied to a closed platform — the underlying software can be self-hosted by anyone.

Community-maintained

Fixes and features come from a real, visible codebase — not a support ticket disappearing into a queue.

In-person and online

The same open-source system runs our point-of-sale on the stall floor and the listings online — one record, not two.
